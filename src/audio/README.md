# 音声に同期する表示データ

`useMicrophone(model)` は VAD による発話状態と、音量・`bands: [低, 中, 高]` を返す。帯域はPCMの代表9周波数をGoertzel法で計算した0〜1の特徴量で、声の響きや子音に伴うスペクトル変化を表示に使う。**音素・単語を認識した結果ではない。** 発話判定と音量・帯域の変化は別に扱う。

`useAgentVoice()` は `start(url)` で約900msのthinking表示の後、同一originのWAVをスピーカーへ再生する。再生と同じAudioContextのAnalyserNodeから音量と帯域を取得し、終了・stop・unmountで音源とcontextを解放する。これはAI出力側の表示を確認するサンプルで、実際のLLMによる応答ではない。マイクは取得しない。

マイク入力とAIサンプルは別contextで共存可能。スピーカーの音が実マイクへ回り込む度合いは端末・echoCancellationの動作に依存するため、本人入力と再生出力の分離確認にはヘッドホンも利用する。

音声の保存・アップロード・文字起こしは行わない。発話判定・音響特徴量・再生はブラウザ内で処理する。

## 表示用の発話ゲート

`speechGate.ts` はSileroの32msごとの発話確率を受け取り、表示用の状態を作る。通常は0.55以上が3フレーム連続、高確度（0.85以上）は2フレーム連続で開始する。無音側（0.35未満）が10フレーム連続すると復帰する。64／96／320msは確率列に対する窓であり、モデル・ブラウザ・描画を含む遅延の実測値ではない。

vad-webの区間収集器は、区間内の離れた陽性フレームも最短発話時間へ加算する。そのイベントを直接赤色に使う方式をやめ、連続した根拠を必要にした。メーターの表示下限は発話判定に流用せず、極小の変動もあるPCMはモデルの確率を優先する。数値的な無音と一定DCだけを除外する。

これは会話のターン終了判定ではない。短い休止で画面を落ち着かせても、それだけでAIが返答を開始してよいとは判定しない。

## 固定入力による比較

`node scripts/audio-evaluate.mjs` は、同じ日本語合成PCMを同梱Silero v6へ通し、同じ確率列を旧ゲートと現ゲートへ与える。`public/samples/eval-results.json` に条件・イベント時刻・確率列を保存する。新たなマイク取得・ユーザー録音・ネットワーク送信は行わない。日本語全体の精度評価ではない。

結果と確認状況は `docs/STATUS.md` と `public/samples/eval-results.json` に記録する。通常音声、-20dB、-30dB、短い「はい」、雑音混合、および各5秒の無音・離散インパルス列・広帯域雑音を比較する。自然話者、実マイクの生活音、相槌、反響、未知雑音に一般化する結果ではなく、境界注釈がないため取り逃し時間の正解値は算出していない。

同梱fixtureはOpen JTalk 1.11とHTS Voice “NIT ATR503 M001” 1.05による日本語合成音声（CC BY 3.0）。出典・テキスト・変更内容は `public/samples/README.md` を参照。`scripts/audio-prepare-fixtures.sh` で再生成でき、中間ファイルは配布対象外の `work/audio/` に置く。
